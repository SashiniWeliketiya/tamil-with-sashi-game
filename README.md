# 🌟 Tamil with Sashi - Children's Day Mini Game!

Welcome to the **Children's Day Special Tamil Learning Game**, created with ❤️ for "Tamil with Sashi"! This interactive web-based mini-game is designed to help children learn basic Tamil vocabulary in a fun, engaging, and playful way.

---

## 🎮 Game Features

- **Children's Day Theme:** Vibrant, colorful, and playful design tailored for kids.
- **Bilingual Learning:** Blends Sinhala and English prompts with authentic Tamil vocabulary and pronunciation guides.
- **Interactive Activities:**
  - *Activity 1: Match the Words* (Matching everyday items like House, Cat, Book, and Star).
  - *Activity 2: Emoji Guessing Quiz* (Fun multiple-choice quiz using emojis).
- **Reward System:** Kids earn stars and score points with celebratory animations and cheers upon completion!

---

## 🚀 How to Play

1. Open the live link:  *( https://sashiniweliketiya.github.io/tamil-with-sashi-game/)*
2. Match the words or answer the emoji quiz questions correctly.
3. Check your score and celebrate your learning milestone!
